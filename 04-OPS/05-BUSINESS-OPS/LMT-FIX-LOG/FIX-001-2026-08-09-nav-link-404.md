# FIX-001 — Nav Link Returns 404 (Services & Pricing)
Date: 2026-08-09
Site: learnmoretechnologies.com
Fixed by: Claude Code + Brian

---

## Problem
Clicking "Services & Pricing" in the homepage nav returned a 404 error.

---

## Root Cause
The LMT homepage uses a **custom HTML nav built inside the page itself** — NOT WordPress Menus or the Customizer. The nav link was pointing to the wrong URL:

```
https://learnmoretechnologies.com/workforce/
```

The Services & Pricing page existed but had the **wrong slug** (`work-with-us` instead of `services-pricing`).

---

## Two-Part Fix

### Part 1 — Fix the page slug
1. Go to **Pages → All Pages**
2. Find the "Services & Pricing" page
3. Click to edit it
4. In the right panel, click the **Slug** field
5. Change it from `work-with-us` to `services-pricing`
6. Save — Yoast will auto-create a redirect from the old URL

### Part 2 — Fix the nav link in the homepage code
The nav is hardcoded inside the **Home page** (not in WordPress Menus).

1. Go to **Pages → Home**
2. Edit with WonderBlocks
3. Open the **Code Editor**
4. Find this line in the NAV section:

```html
<a href="https://learnmoretechnologies.com/workforce/" class="nav-pill">Services & Pricing</a>
```

5. Change it to:

```html
<a href="https://learnmoretechnologies.com/services-pricing/" class="nav-pill">Services & Pricing</a>
```

6. Save the page
7. Clear cache (Caching button in admin bar)

---

## Key Facts to Remember
- The LMT homepage nav is NOT in Appearance > Menus
- The nav is NOT in the Customizer
- The nav is NOT in header.php (header.php uses GeneratePress hooks)
- The nav lives inside the **Home page HTML block** (WonderBlocks code editor)
- The full corrected homepage code is saved at: `Desktop/LMT-homepage-fixed.html`
- Theme: GeneratePress + BuddyBoss reset styles
- Page builder: WonderBlocks
