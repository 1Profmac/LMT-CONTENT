# SOP-06 — Build in Canva
## Brand standards + step-by-step for any Canva project

**Purpose:** Build any LMT/50+TechBridge asset in Canva on-brand, every time.
**Trigger:** Any new Canva design needed — slide, carousel, thumbnail, flyer, etc.
**Owner:** Brian McKinney
**Time required:** 15-60 min depending on project
**Frequency:** Multiple times per week

---

## QUICK REFERENCE
1. Create design → set canvas size
2. Background: #0E1C2F (navy)
3. Fonts: Playfair Display (headings) + DM Sans (body)
4. Colors: White #FFFFFF | Gold #C8942E | Muted #A8B8CC
5. Build → animate (if video) → export in correct format

---

## BRAND STANDARDS (memorize these)

| Element | Value |
|---|---|
| Navy background | #0E1C2F |
| Gold accent | #C8942E |
| White text | #FFFFFF |
| Muted/secondary text | #A8B8CC |
| Heading font | Playfair Display Bold |
| Body font | DM Sans Regular / Medium / Bold |
| Gold = action | Always use gold for CTAs and key callouts |

## CANVAS SIZES

| Project | Size |
|---|---|
| YouTube thumbnail | 1280 x 720 px |
| LinkedIn carousel | 1080 x 1080 px |
| LinkedIn banner | 1584 x 396 px |
| Lesson screen demo | 1080 x 1920 px |
| Library flyer | 8.5 x 11 in |
| Postcard | 6 x 4 in |
| Business card | 3.5 x 2 in (bleed: 3.75 x 2.25 in) |

## STEP-BY-STEP

### Step 1 — Open and Set Size
1. canva.com → log in → **Create a design**
2. Choose size from table above (or Custom dimensions)

### Step 2 — Set Background
1. Click background (empty canvas)
2. Click color square in top toolbar
3. Type: `#0E1C2F` → Enter

### Step 3 — Add Fonts
1. Left sidebar → **Text** → add text box
2. Font dropdown: type **Playfair Display** (headlines) or **DM Sans** (body)
3. Colors: `#FFFFFF` headings | `#A8B8CC` secondary | `#C8942E` gold

**Min font sizes:**
- Lesson slides: 24pt
- Thumbnail text: 48pt+
- Print body: 9pt
- Business card: 7-8pt

### Step 4 — Add Brand Elements
- **Gold line:** Elements → Shapes → Rectangle → color #C8942E → 2-4px height → full width
- **Gold arrow:** Elements → search "arrow" → color #C8942E → point toward CTA
- **Phone mockup:** Elements → search "iPhone frame" → outline only → fill 80% of slide

### Step 5 — Build Layout
- **Slides/carousel:** Build slide 1 fully → Ctrl+D (duplicate) → update only what changes
- **Print:** Logo top-left → gold line → headline → body text → CTA → website + contact
- **Business cards:** Build navy version first → duplicate → swap background for each color version

### Step 6 — Animations (video/lesson slides only)
- Transitions: **Fade** only (not distracting)
- Gold arrows: **Bounce** or **Pulse**
- Checkmarks: **Pop**
- Slide duration: **4 seconds** (lesson slides)

### Step 7 — Export

| Project Type | Format | Settings |
|---|---|---|
| Video | MP4 Video | 1080p |
| Print (flyer, card, postcard) | PDF Print | Check "Crop marks and bleed" |
| Social (carousel, thumbnail) | PNG | High quality |

### Step 8 — Save and Rename
Click design name at top → rename:
`LMT-[Project]-[Version]-2026`
Example: `LMT-Lesson3-Thumbnail-2026`

---

## TIPS
- **Duplicate, don't start over.** Build one perfectly, then duplicate and swap.
- **Lock background.** Right-click background → Lock. Prevents accidental moves.
- **Brand kit.** Add LMT colors to Canva brand kit — they appear first in the color picker.
- **Export video without sound first.** Get the visual right, then add voiceover via HeyGen.
- **Magic Design.** Paste prompts from CANVA-AI-PROMPTS.md into Canva's Magic Design for rough drafts.
