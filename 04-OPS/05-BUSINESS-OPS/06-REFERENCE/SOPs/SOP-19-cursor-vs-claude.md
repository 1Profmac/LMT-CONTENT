# SOP-19 — Cursor vs Claude Code
## When to use each AI tool — and how to combine them

**Purpose:** Prevent paying twice for the same work. Cursor is cheap for research. Claude Code knows your business. Use each for what it does best.
**Trigger:** Any time you start a new task and aren't sure which tool to use
**Owner:** Brian McKinney
**Time required:** 2 minutes to decide
**Frequency:** Every work session

---

## QUICK REFERENCE
1. Research, web search, cheap questions → Cursor
2. Anything needing LMT context, brand, SOPs, files → Claude Code
3. Build files (PPT, HTML, markdown) → Claude Code
4. Paste Cursor research into Claude → Claude turns it into your deliverable
5. Files live in Google Drive — both tools access same folder

---

## STEP-BY-STEP

### STEP 1 — Ask: does this task need to know who Brian McKinney is?
- YES → use Claude Code
- NO → use Cursor

### STEP 2 — Use Cursor for research
- Open Cursor → new chat
- Ask research questions: grants, competitors, tools, industry data
- Copy the useful output

### STEP 3 — Bring research to Claude Code
- Paste Cursor's output into Claude Code
- Say what you need: "Turn this into a grant paragraph using our verified numbers"
- Claude builds the final deliverable using your brand, voice, and file structure

### STEP 4 — Claude Code builds the file
- Claude saves to `G:\My Drive\LMT-CONTENT` (correct path after Google Drive move)
- Google Drive syncs automatically — file appears on all devices
- Claude commits to GitHub if it's a code/text file worth versioning

### STEP 5 — Open finished files in the right app
- PPT → PowerPoint
- PDF → browser or File Explorer double-click
- HTML → browser or Cursor for editing
- Markdown/code → Cursor or Claude Code

---

## DECISION POINTS

**If the task is pure research (no LMT files needed):**
- Use Cursor — faster and cheaper

**If the task needs your SOPs, TODO, brand voice, verified numbers, or file structure:**
- Use Claude Code — it knows all of that

**If you need to edit a file Cursor generated:**
- Bring it to Claude Code, or open it in the right app (PowerPoint, etc.)

**If you need to view a PDF:**
- File Explorer double-click, or drive.google.com in browser
- Cursor and Claude Code cannot render PDFs

---

## COMMON MISTAKES
- Using Claude Code for generic research (costs more, no advantage over Cursor)
- Using Cursor for anything that needs your brand voice or LMT files (it doesn't know them)
- Trying to open PDFs or PPTs inside Cursor (binary files — not possible)
- Forgetting to reopen Cursor to `G:\My Drive\LMT-CONTENT` after the Google Drive move

## TOOLS & ACCESS NEEDED
- Cursor (installed) — research and code editing
- Claude Code (this tool) — build, operate, manage LMT files
- Google Drive mounted at `G:\My Drive` — shared file location for both tools
- GitHub `1Profmac/LMT-CONTENT` — version history for code and text files
