## How to Add a New SOP
1. Brain dump the process (5 min) — talk or type it out like you're training someone
2. Paste into Claude: "Turn this into an SOP using Craig Hewitt's format"
3. Review, fix what's wrong, add what only you know
4. Save as `SOP-[next number]-[short-name].md` in this folder
5. Add a row to this index

> A rough SOP that exists beats a perfect SOP that doesn't. — Craig Hewitt
