## BRAND STANDARDS (use on every Canva project)

| Element | Value |
|---|---|
| Navy background | #0E1C2F |
| Gold accent | #C8942E |
| Gold hover | #E8B84B |
| White text | #FFFFFF |
| Muted text | #A8B8CC |
| Heading font | Playfair Display (Bold or Black) |
| Body font | DM Sans (Regular, Medium, Bold) |
| Gold = action | Always use gold to say "tap here" or "look here" |

## STEP-BY-STEP: HOW TO BUILD ANYTHING IN CANVA

### Step 1 — Open Canva and Set Canvas Size

1. Go to canva.com and log in
2. Click **Create a design** (top right)
3. Choose the right size for your project:

| Project | Canvas Size |
|---|---|
| Lesson screen demo (vertical video) | 1080 x 1920 px |
| LinkedIn carousel slide | 1080 x 1080 px |
| LinkedIn banner | 1584 x 396 px |
| Business card front/back | 3.5 x 2 in (with bleed: 3.75 x 2.25 in) |
| Library flyer | 8.5 x 11 in |
| Postcard | 6 x 4 in |
| Speaker sheet | 8.5 x 11 in |

---

### Step 2 — Set the Background

1. Click the background area (empty canvas)
2. Click the color square in the top toolbar
3. Type in the hex code: **#0E1C2F** (navy)
4. Press Enter

---

### Step 3 — Add Fonts

Canva has both LMT fonts built in. To use them:

1. Click **Text** in the left sidebar
2. Add a text box
3. In the font dropdown, type: **Playfair Display** (for headlines) or **DM Sans** (for body)
4. Set color to **#FFFFFF** (white) for headings, **#A8B8CC** for secondary text, **#C8942E** for gold callouts

**Minimum font sizes:**
- Lesson slide callouts: 24pt
- Print body text: 9pt
- Business card body: 7–8pt
- Speaker sheet body: 10pt

---

### Step 4 — Add Brand Elements

**Gold accent line:**
- Elements → Shapes → Rectangle
- Color: #C8942E, height: 2–4px, full width

**Gold arrow (for lesson slides):**
- Elements → search "arrow"
- Pick a simple line arrow, color it #C8942E
- Point toward what the user should tap

**Checkmark:**
- Elements → search "checkmark"
- Color: #C8942E or white on gold circle

**Phone mockup (for lesson slides):**
- Elements → search "iPhone frame" or "phone mockup"
- Pick a clean outline-only frame (not a photo)
- Resize to fill ~80% of the slide, center it

---

### Step 5 — Build Your Slides or Layout

**For lesson screen demos:**
1. Build Slide 1 fully
2. Click the slide thumbnail → Duplicate (Ctrl+D)
3. Update only what changes on each slide
4. Repeat for each slide
5. See `CANVA-SCREEN-DEMOS.md` for full slide-by-slide specs

**For print materials (flyer, postcard, speaker sheet):**
1. Set background to navy #0E1C2F
2. Add logo top-left (or top-center for flyer)
3. Add gold accent line under logo
4. Add headline in Playfair Display Bold, white
5. Add body text in DM Sans, #A8B8CC
6. Add gold CTA button or gold text link at bottom
7. Add website + contact info in small DM Sans

**For business cards:**
1. Build Version 1 (navy) front first — all text + layout
2. Add back page in same design file
3. Duplicate all pages → change background color for Version 2 (white), 3 (gold), 4 (red)
4. See `BUSINESS-CARD-PRINT-PACKAGE/business-card-canva-specs.md` for exact specs

---

### Step 6 — Add Animations (lesson slides only)

1. Click the element to animate
2. Click **Animate** in the top toolbar
3. Use only **Fade** transitions between slides (not distracting)
4. For gold arrows: use **Bounce** or **Pulse**
5. For checkmarks: use **Pop** (scale in effect)
6. Set slide duration: **4 seconds per slide**

---

### Step 7 — Export

**For video (lesson screen demos):**
1. Click **Share** (top right)
2. Click **Download**
3. Format: **MP4 Video**
4. Quality: **1080p**
5. Save as: `lesson1-screen-demo.mp4` (or lesson2, lesson3)

**For print (flyer, postcard, speaker sheet, business card):**
1. Click **Share** → **Download**
2. Format: **PDF Print**
3. Check **Crop marks and bleed** (for business cards and postcards)
4. Save with the filename from the specs file

**For social (LinkedIn carousel, banner):**
1. Click **Share** → **Download**
2. Format: **PNG** (highest quality)
3. Or **PDF** if multi-page carousel

---

### Step 8 — Save and Rename in Canva

1. Click the design name at the top of Canva (defaults to "Untitled design")
2. Rename it clearly: `LMT-Lesson1-ScreenDemo-2026` or `LMT-BusinessCard-Navy-2026`
3. Canva auto-saves — your design stays in your account

## TIPS

- **Duplicate, don't start over.** Build one version perfectly, then duplicate and swap colors/text.
- **Lock background layers.** Right-click background → Lock. Prevents accidental moves.
- **Use Canva's brand kit.** Add LMT colors (#0E1C2F, #C8942E, #FFFFFF) to your brand kit so they appear first in the color picker.
- **Magic Design for slides.** Paste prompts from `CANVA-AI-PROMPTS.md` directly into Canva's Magic Design (wand icon). Good for rough drafts.
- **Export video without sound first.** Get the visual right, then add voiceover via HeyGen or Canva Present & Record.
