# WHERE TO FIND THINGS
## The Salt Rule: everything has one home. It's always there.

---

| What you need | Where it lives |
|---|---|
| Lesson videos + scripts | `01-LESSONS/LESSON-1` `LESSON-2` `LESSON-3` |
| Articles, videos, posts | `02-LINKEDIN/articles/[article-name]/` |
| Book chapters | `03-BOOK/` |
| CSS, brand assets, production guides | `04-ASSETS/` |
| Client / side work | `05-SIDE-WORK/` |
| Marketing, outreach, pitch deck, funding | `06-MARKETING/` |
| Weekly board meeting | `WEEKLY-BOARD-MEETING.md` ← right here |
| Weekly site checklist | `WEEKLY-SITE-MAINTENANCE.md` ← right here |
| What's next / content schedule | `NEXT STEPS - Content Schedule.md` ← right here |

---

## Every article folder looks the same:
```
02-LINKEDIN/articles/[name]/
  ARTICLE.md                 ← web + LinkedIn post
  VIDEO-SCRIPT.md            ← long-form video
  YOUTUBE-SHORT-SCRIPT.txt   ← 60-second short
  PODCAST-SCRIPT.txt         ← podcast episode
  ELEVENLABS-VOICEOVER.txt   ← paste into ElevenLabs
```

## Every lesson folder looks the same:
```
01-LESSONS/LESSON-X/
  lessonX.txt        ← WordPress page content
  YOUTUBE/           ← title, description, tags, LinkedIn post
  YOUTUBE/ALL-FORMATS/ ← every video format rendered
```
