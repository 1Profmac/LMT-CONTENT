# B-Roll Stats Sheet — "$850 Billion"
## Text overlays + Canva clip prompts for each stat

---

## HOW TO BUILD EACH STAT CLIP

1. Open Canva → Create a design → Video → 1080 x 1920 (vertical)
2. Generate B-roll clip in Magic Media using the prompt below
3. Add the stat text overlay on top (gold text, navy background flash)
4. Export as MP4
