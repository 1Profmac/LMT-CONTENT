## HOW TO BUILD ALL 4 FAST

1. Build Version 1 (navy) first — all text + elements
2. Duplicate page 1 → change background + text colors for Version 2
3. Duplicate again for Version 3 and Version 4
4. Repeat for back pages
5. Total: 8 pages (4 fronts + 4 backs)

## PRINTING
- Print with Canva (easiest) or Share → Download → PDF Print with crop marks + bleed
- Text built in Canva = vector = crisp print
- Only upload logos + QR as images
