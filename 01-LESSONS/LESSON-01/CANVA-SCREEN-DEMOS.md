# Canva Screen Demo Builds — All 3 Lessons

## Setup (Do Once)

1. Open Canva → Create Design → Custom size **1080 x 1920 px** (vertical video)
2. Search Elements → "iPhone mockup" or "phone frame" → pick a clean one
3. Save this as a template — duplicate it for each lesson
4. Set all slide transitions to "Fade" (smooth, not distracting)
5. Set slide duration: **4 seconds per slide** (gives time to read)

---

## How to Get Screenshots Without a Real Phone

Use these free online phone simulators:

- **iPhone:** Search Canva for "iOS settings screenshot" in photos — OR use appetize.io (free iOS simulator in browser)
- **Android:** Same approach — search Canva stock photos for "android settings screenshot"
- **Cleanest option:** Use Canva's own mockup frames + recreate the screens as simple graphics (rounded rectangles, toggles, sliders made from Canva shapes)

**Simplest path:** Just recreate simplified versions of each screen using Canva shapes. Doesn't need to be pixel-perfect — needs to be CLEAR.

## DESIGN RULES FOR ALL SLIDES

| Rule | Why |
|------|-----|
| Max 6 words in callout text | They're reading fast |
| One action per slide | Don't overwhelm |
| Gold = "tap this" or "look here" | Consistent visual language |
| Phone frame stays same position every slide | Eyes don't jump around |
| 4 seconds per slide minimum | Gives time to process |
| Use Canva "Fade" transitions only | Smooth, not distracting |
| Font: 24pt minimum for callouts | Must read on phone screen |
| Brand colors: dark blue bg + gold highlights | Matches 50+TechBridge |

## VOICEOVER OPTIONS

**Option 1: Silent with text callouts (fastest to build)**
- All instruction is in the text below the phone
- No audio needed — works on mute

**Option 2: Canva Present & Record (your voice)**
- Click Present & Record in Canva
- Talk through each slide as it advances
- Export as MP4 with your voice baked in

**Option 3: HeyGen voiceover (avatar voice only, no face)**
- Export Canva slides as silent MP4
- Upload to HeyGen → add voiceover using same avatar voice
- Matches the intro video tone

**Recommendation: Option 1 first (get it done), add voice later if you want.**
