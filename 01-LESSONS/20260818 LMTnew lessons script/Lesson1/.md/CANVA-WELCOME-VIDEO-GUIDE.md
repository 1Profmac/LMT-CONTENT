# Canva Welcome Video — Script-to-Slide Timing Guide

## HOW TO USE THIS IN CANVA
1. Import welcome-video-slides.pptx into Canva (Create → Import file)
2. Add your ElevenLabs MP3 as the audio track
3. Set each slide duration to the seconds shown below
4. Apply animation where noted
5. Add HeyGen PIP on slides 1 and 7
