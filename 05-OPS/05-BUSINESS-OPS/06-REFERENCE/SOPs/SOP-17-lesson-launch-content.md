# SOP-17 — Lesson Launch Content Package
## Full content package every time a new lesson goes live

**Purpose:** Every new lesson needs 7 assets to launch properly — carousel, LinkedIn, Facebook, YouTube Short, blog, Yoast SEO. This SOP prevents rebuilding from scratch every time.
**Trigger:** A new LearnDash lesson is live and ready to promote
**Owner:** Brian McKinney
**Time required:** 30-45 minutes
**Frequency:** Every new lesson launch

---

## QUICK REFERENCE
1. Run `/content-day [lesson topic]` — generates all 7 assets at once
2. Build carousel in Canva (6 slides, navy/gold brand)
3. Publish blog article to WordPress + Yoast SEO fields
4. Post LinkedIn (carousel + hook copy, YouTube link in comments)
5. Post Facebook + record YouTube Short via HeyGen

---

## STEP-BY-STEP

### STEP 1 — Generate the Content Package
- Run `/content-day [topic]` in Claude
- Include: lesson name, 3 skills taught, target audience, signup URL
- Output: blog article, LinkedIn post, Facebook post, YT Short script, YT metadata, Yoast SEO fields
- Signup URL: `https://50plustechbridge.com/start-free-lessons/`

### STEP 2 — Build the LinkedIn Carousel in Canva
- Open Canva → search "LinkedIn Carousel" → use 50+TechBridge template
- 6 slides: Cover → Skill 1 → Skill 2 → Skill 3 → Quick Win → CTA
- Brand: background `#0E1C2F`, accent `#C8942E`, font DM Sans
- Final slide CTA: `50plustechbridge.com/start-free-lessons`
- Export as PDF (LinkedIn carousels are PDF uploads)

### STEP 3 — Publish Blog Article
- WordPress → Posts → Add New
- Paste article from content package
- Fill Yoast SEO fields (keyphrase, title, meta desc, slug)
- Set featured image (lesson thumbnail or Dr. Maya image)
- Publish

### STEP 4 — Post to LinkedIn
- Upload carousel PDF as the post media
- Paste LinkedIn hook copy above it
- In first comment: paste YouTube link
- Post + engage comments for first 30 minutes

### STEP 5 — Post to Facebook + Record YouTube Short
- Facebook: paste Facebook post copy → add lesson thumbnail image → post
- YouTube Short: paste HeyGen script → record with Dr. Maya avatar → upload with metadata from content package

## DECISION POINTS

**If the lesson is behind a signup wall:**
- LinkedIn/Facebook link goes to the SIGNUP page, not the lesson
- YouTube full video link goes in LinkedIn comments (not the post body)
- Carousel is the lead magnet — gives value, drives to signup

**If you don't have a carousel ready:**
- Post the LinkedIn text-only version first
- Come back and add carousel as a separate post later

---

## COMMON MISTAKES
- Linking directly to the LearnDash lesson URL (people hit the wall and bounce)
- Posting the YouTube link as the main CTA instead of the signup page
- Forgetting to put YouTube link in the LinkedIn comments
- Using retired stats (347 adults, 3X completion) — always use verified numbers
