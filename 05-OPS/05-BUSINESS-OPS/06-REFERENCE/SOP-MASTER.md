## 1. VIDEO PRODUCTION — CANVA BUILD

**Source:** `03-MARKETING/06-MARKETING/06-VIDEO/CANVA-VIDEO-BUILD-PROCESS.md`
**Assets needed before starting:**
- ElevenLabs voiceover MP3
- PPT slides exported as PNG or PDF
- HeyGen talking head MP4
- B-roll images or clips (from Gemini or stock)

### STEP 1 — ELEVENLABS VOICEOVER
1. Open ElevenLabs → Text to Speech
2. Paste script
3. Select voice: **Brian McKinney**
4. Model: **Eleven Multilingual v2** | Speed: **1.0**
5. Generate → Download MP3 → save as `[Lesson]-Voice-Over-FINAL.mp3`

### STEP 2 — HEYGEN TALKING HEAD
> WARNING: Use HeyGen directly — NOT the Canva app. The Canva app only generates 2.5 seconds.

1. Go to **app.heygen.com**
2. Create Video → Scene by scene → Build it yourself
3. Script panel: click audio icon → upload ElevenLabs MP3
4. Avatar: **Brian McKinney** (Bright Horizon look)
5. Motion Engine: **Avatar V**
6. Avatar Background → **Remove** (transparent)
7. Layout → **Circle** for PIP style
8. Click **Generate** → download MP4
9. Upload MP4 to Canva via Uploads

**To add to slides:**
- Drag HeyGen MP4 onto slide → position bottom corner
- Brian appears on slide 1 (open) and slide 7 (close) only

### STEP 3 — BUILD IN CANVA

**3A — Import Slides**
1. Click Uploads → upload slides PDF
2. Click **Apply all pages** when prompted

**3B — Add Audio**
1. Uploads → upload voiceover MP3
2. Drag MP3 onto timeline → spans all slides automatically

**3C — Set Slide Durations**
Click each slide's navy bar in the timeline → drag RIGHT EDGE to set duration.

| Slide | Content | Duration |
|-------|---------|----------|
| 1 | Welcome / Cover | 25s |
| 2 | Fridge Line | 20s |
| 3 | Stats | 35s |
| 4 | Map (3 lessons) | 45s |
| 5 | Safety | 20s |
| 6 | Homework | 25s |
| 7 | Closing | 35s |
| **TOTAL** | | **3:25** |

**3D — Add B-Roll**
Upload clips → drag onto appropriate slides → resize or position

**3E — Add HeyGen PIP**
Drag HeyGen MP4 onto slides 1 and 7 → resize to bottom corner

### STEP 4 — PREVIEW AND EXPORT
1. Click **Preview** — watch full video, check sync
2. Share → Download → **MP4 Video**
3. Save as `[lesson]-video-FINAL.mp4`

### STEP 5 — UPLOAD TO YOUTUBE
1. YouTube Studio → Upload
2. Visibility: **Unlisted**
3. Copy video ID from URL
4. Paste video ID into LearnDash lesson page
5. Mark TODO.md complete

**Notes:**
- Canva does NOT auto-sync slide durations to voiceover — set each manually
- Beat Sync only works with music, not voiceover
- Always preview before downloading

## 4. HOW TO BUILD ANYTHING IN CANVA

**Source:** `06-ASSETS/CANVA-BUILDS/HOW-TO-BUILD-IN-CANVA.md`

### Brand Standards (use on every project)

| Element | Value |
|---|---|
| Navy background | #0E1C2F |
| Gold accent | #C8942E |
| White text | #FFFFFF |
| Muted text | #A8B8CC |
| Heading font | Playfair Display Bold |
| Body font | DM Sans Regular/Medium/Bold |

### Canvas Sizes

| Project | Size |
|---|---|
| Lesson screen demo | 1080 x 1920 px |
| LinkedIn carousel | 1080 x 1080 px |
| LinkedIn banner | 1584 x 396 px |
| Business card | 3.5 x 2 in (bleed: 3.75 x 2.25 in) |
| Library flyer | 8.5 x 11 in |
| Postcard | 6 x 4 in |
| YouTube thumbnail | 1280 x 720 px |

### Step-by-Step Build

**Step 1 — Open and Set Size**
1. canva.com → Create a design → choose size from table above

**Step 2 — Set Background**
1. Click background → color square → type `#0E1C2F` → Enter

**Step 3 — Add Fonts**
1. Text → add text box → font: **Playfair Display** (headings) or **DM Sans** (body)
2. Colors: #FFFFFF headings | #A8B8CC secondary | #C8942E gold callouts
3. Min font sizes: lesson slides 24pt | print body 9pt | business card 7-8pt

**Step 4 — Add Brand Elements**
- Gold accent line: Elements → Shapes → Rectangle → #C8942E, 2-4px height
- Gold arrow: Elements → search "arrow" → color #C8942E
- Phone mockup: Elements → search "iPhone frame" → outline only, fill 80% of slide

**Step 5 — Build Slides/Layout**
- Duplicate slides (Ctrl+D) → update only what changes
- Print materials: logo top-left → gold accent line → headline → body → CTA → contact

**Step 6 — Animations (lesson slides only)**
- Animate → use **Fade** for transitions
- Gold arrows: **Bounce** or **Pulse**
- Checkmarks: **Pop**
- Duration: 4 seconds per slide

**Step 7 — Export**
- Video: Share → Download → **MP4 Video** → 1080p
- Print: Share → Download → **PDF Print** → check "Crop marks and bleed" for cards/postcards
- Social: Share → Download → **PNG**

**Step 8 — Save and Rename**
Click design name at top → rename: `LMT-[Project]-[Version]-2026`

### Tips
- Duplicate, don't start over
- Right-click background → Lock to prevent accidental moves
- Add LMT colors to your brand kit so they appear first in the color picker
- Export video without sound first — get visual right, then add voiceover

## 7. YOUTUBE SEO PACKAGE

**Source:** `03-MARKETING/06-MARKETING/01-PLAYBOOKS/YOUTUBE-SEO-GUIDE.md`
**Rule: Every video gets this package before upload. No exceptions.**

### 7-Item Package

**1. TITLE** (most important)
- Under 60 characters | Front-load the keyword | Use a number | Create curiosity gap
- Formula: `[Keyword] + [Hook/Benefit] + [Qualifier]`
- Good: `"AI Training for Adults 50+ | What 13 Locations Learned"`
- Bad: `"My Thoughts on AI"`

**2. DESCRIPTION**
First 2 lines must hook AND contain your keyword.
```
[Stat or hook sentence with primary keyword]
[What the viewer will learn + CTA]

In this video:
- [Key point 1]
- [Key point 2]
- [Key point 3]

Resources:
- Free course: https://learnmoretechnologies.com/join-now/
- Book a consult: https://cal.com/brian-mckinney-mrtu8q

About 50+TechBridge:
AI and digital skills training designed for adults 50+. 13 locations. MBE Certified. WIOA Eligible.

Brian McKinney | Founder, Learn More Technologies
https://learnmoretechnologies.com

#agentic50 #Adults50Plus #AITraining #AgeTech #WorkforceDevelopment #DigitalInclusion #Over50 #WIOA
```

**3. TAGS (15-20 per video)**
Permanent tags (every video):
`50+TechBridge, adults over 50, AI training, digital skills, ageism, AgeTech, workforce development, older adults, Brian McKinney, Learn More Technologies, AI for seniors, technology training, WIOA, digital inclusion, over 50`

Add 5-8 topic-specific tags per video.

**4. THUMBNAIL**
- Your face, large, with expression
- 3-5 words MAX as text overlay
- High contrast: gold on navy or white on dark
- Readable on a phone | ONE clear focal point
- Build in Canva: 1280x720, export PNG

**5. CHAPTERS**
```
0:00 Introduction
0:15 The Problem
1:02 What We Found
2:15 The Solution
```
Must start at 0:00. Each chapter minimum 10 seconds.

**6. END SCREEN + CARDS**
- End screen (last 20 sec): Subscribe + best video + newest video
- Cards: 1-2 clickable links to related videos

**7. PLAYLIST**
Add every video to a playlist. Playlists rank separately in YouTube search.
- "50+TechBridge Course Preview"
- "AI Training for Adults 50+"
- "The Numbers Nobody Told You"

## 8. CONTENT DEVELOPMENT PROCESS

**Source:** `05-OPS/05-BUSINESS-OPS/02-STRATEGY/CONTENT-DEVELOPMENT-PROCESS.md`

### Step 1 — Plain Text Draft
- Write as plain text first — no formatting, no links
- Pick ONE focus keyphrase (what someone would Google)
- Put keyphrase in first 100 words
- H2/H3 subheadings every 200-300 words
- Minimum 800 words (pillar) or 500+ (shorter posts)
- End with a CTA

### Step 2 — SEO Layer (before WordPress)

**Internal Links (3-5 per article):**
- Use descriptive anchor text — never "click here"
- Cross-link using the 4-category system (Problem ↔ Opportunity ↔ Solution ↔ Guide)

**External Links (1-2):**
- AARP, RAND, HBR, DOL/WIOA, EEOC — opens in new tab

**Yoast SEO fields to prepare:**
```
Focus keyphrase: [exact search term]
SEO title: [under 60 chars, keyphrase near front]
Meta description: [under 155 chars, keyphrase included, ends with hook]
Slug: [short-keyword-rich-slug]
SEO keywords: [keyword1, keyword2, keyword3, keyword4, keyword5]
Alt text for featured image: [describes image + includes keyphrase]
```

**CTA at bottom of every article:**
- Booking: https://cal.com/brian-mckinney-mrtu8q
- Course: https://learnmoretechnologies.com/join-now
- Email: hello@learnmoretechnologies.com

### Step 3 — WordPress Copy
- Paste using STANDARD BLOCKS ONLY: Heading, Paragraph, List, Image
- NO BuddyBoss shortcodes, NO LearnDash shortcodes in blog posts
- **Verification test:** Right-click → View Page Source → Ctrl+F for a sentence. If it's not in the source, Google can't see it.
- Fill Yoast box: keyphrase + SEO title + meta description → confirm green

### Step 4 — Review Before Publishing
1. Preview in incognito window — does it render?
2. View Page Source → Ctrl+F test — content in HTML?
3. Yoast light GREEN (not orange/red)
4. Readability score GREEN
5. Featured image has alt text
6. All internal links work
7. CTA with booking link at bottom

### Step 5 — Request Indexing
1. Google Search Console → URL Inspection
2. Paste new article URL → **REQUEST INDEXING** (once — never repeat)
3. Do NOT change the slug after this point

### Step 6 — Content Engine (One Article = One Week)

| Day | Action |
|---|---|
| Monday | Publish WP article → post excerpt on LinkedIn + FB |
| Tuesday | Build Canva carousel from article |
| Wednesday | Post carousel on LinkedIn + FB → send Agentic50 newsletter |
| Thursday | Repost carousel to FB Groups |
| Friday | Text engagement post on LinkedIn + FB |

Every post includes: booking link + #agentic50 + CTA + link back to article

### Step 7 — Weekly Monitoring (Every Monday)
- Google Search Console → Pages (how many indexed?)
- Search Console → Performance (impressions, clicks, position)
- LinkedIn Analytics → post performance
- HubSpot → new contacts from content

### DO NOT
- Change slugs after publishing
- Use BuddyBoss shortcodes in articles
- Publish without Yoast fields filled in
- Publish without the View Source test
- Resubmit the same URL to Google multiple times
- Skip the booking link CTA
- Inflate proof points — use verified numbers only

## 11. LEARNER HOW-TOS

*These are participant-facing guides used in class.*

### 11A — How to Use the Barb App
**Source:** `05-OPS/05-BUSINESS-OPS/digital-pioneer/HOWTO-barb-app.md`

1. Open the app → tap **"Ask Barb"**
2. Type your question in plain everyday words
3. Tap Send (arrow button)
4. Read Barb's answer → tap again to ask a follow-up

Examples: "How do I video call my grandchildren?" | "What does Medicare Part B cover?"

If stuck: Check your internet connection — Barb needs to be online.

---

### 11B — How to Ask Your First Question with ChatGPT
**Source:** `01-LESSONS/20260818 LMTnew lessons script/Lesson2/TXT/HOWTO-lesson-02b-use-chatgpt-phone.md`

1. Open ChatGPT on your phone → tap the message box at the bottom
2. Type the starter prompt:
   > *"I'm new to AI and I'm over 50. Please explain [your topic] in five simple steps, using clear language."*
3. Press Enter or tap the arrow
4. Watch the response appear word by word — that's AI responding to YOU
5. Read the whole answer — scroll to the top
6. Ask yourself: *Is this useful?* Not perfect. Just useful.

If stuck: If the app asks you to log in, tap "Log in" and enter your email + password.
