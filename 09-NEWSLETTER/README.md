
## Next Edition = EDITION-03

Create folder `EDITION-03/` with:
- `agentic50-edition-3.md` (content draft)
- `agentic50-edition-3-ready.html` (Mailchimp HTML)

## How to Send

1. Log into Mailchimp
2. Create new Campaign → Email
3. Select audience
4. Enter subject line + preview text from the .md file
5. Choose Legacy Builder → Code tab
6. Paste HTML from the `-ready.html` file
7. Preview → Test → Send
